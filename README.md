# Portfolio

Portfolio website with modern Swiss precision design and interactive skills visualization.

## Features

- **Smooth Animations**: GSAP-powered scroll animations with Lenis smooth scrolling
- **Interactive Skills Section**: Category-based filtering with animated progress bars
- **3D Effects**: Tilt effects on featured project cards using Three.js
- **Responsive Design**: Optimized for all screen sizes
- **Modern Tech Stack**: Built with Vite, vanilla JavaScript, and CSS

## Tech Stack

- **Build Tool**: Vite
- **Animations**: GSAP with ScrollTrigger
- **3D Graphics**: Three.js
- **Smooth Scroll**: Lenis
- **Styling**: Custom CSS with CSS Variables

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
